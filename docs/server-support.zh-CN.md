# 服务器功能支持对照

[English](server-support.md) | 简体中文

更新日期：2026-11-01。代码基线：`c2d5826`。

本文记录 **Lumy Player 当前客户端的接入情况**，不代表服务器产品的完整能力。表中的“已接入”依据代码与接口测试；实际可用性还取决于服务器版本、账号权限、媒体元数据和设备能力。“未接入”也不等于服务器本身不支持。

播放策略与设备解码能力见[播放与解码支持](playback.zh-CN.md)，匿名媒体实播与性能边界见[格式兼容性与播放性能参考](playback-compatibility-performance.zh-CN.md)。

| 账号下服务器发现与地址探测 | 已接入，包含局域网、远程和中继候选地址 | 手动指定地址 | 手动指定地址 | 手动指定地址 |

所有服务器都支持添加多条记录、切换、重命名和删除。手机扫码输入要求手机与电视处于同一局域网；旧版 Android 的 HTTPS 兼容性见 [TLS 说明](tls-compatibility.zh-CN.md)。

## 播放、音轨与字幕

下表的转码能力要求客户端允许转码，且服务端允许相应转换。声明允许复制流，不代表服务端每次都会复制。

| 能力 | Plex | Jellyfin | Emby | 飞牛影视 |
|---|---|---|---|---|
| 原画播放、续播、音轨选择、外挂字幕 | 已接入 | 已接入 | 已接入 | 已接入 |
| 画质 / 码率限制、失败后转码回退 | 已接入 | 已接入 | 已接入 | 已接入 |
| 服务端转码输出 | HLS / TS | HLS / TS；保留内封字幕时用 MKV | HLS / TS；保留内封字幕时用 MKV | 原生 HLS，视频请求 H.264 |
| 只换封装、复制视频流 | 已接入，服务端决定 | 已接入，服务端决定 | 已接入，服务端决定 | 未验证成功，当前重新编码视频 |
| 转码音频保留 | 协商 AAC / AC3 / EAC3 / MP3 | 协商支持格式；MKV 可声明更多原编码 | 协商支持格式；MKV 可声明更多原编码 | 本机能解码时保留 AAC / AC3 / EAC3，其他格式转 AAC |
| 转码音频声道 | AC3 请求上限 5.1，EAC3 请求上限 7.1 | 请求上限 8 声道 | 请求上限 8 声道 | 当前目标为双声道或 5.1，不提供 7.1 |
| 内封字幕在转码输出中供本机渲染 | HLS 不保留，需外挂或烧录 | 条件支持，所选字幕随 MKV 输出 | 条件支持，所选字幕随 MKV 输出 | 以烧录为主，无通用 MKV 保留路径 |
| 服务端字幕烧录 | 已接入 | 已接入 | 已接入 | 已接入 |
| HDR → SDR 请求 | 已接入，依赖服务端色调映射 | 已接入，依赖服务端色调映射 | 已接入，依赖服务端色调映射 | 已接入，HDR10 样本已验证 |
| 多段文件拼接（CD1 / CD2） | 已接入 | 未接入，仅使用当前媒体源 | 未接入，仅使用当前媒体源 | 未接入，仅使用当前媒体源 |
| 章节列表与跳转 | 条件支持，需章节数据 | 条件支持，需章节数据 | 条件支持，需章节数据 | 兼容映射保留，待验证 |
| 片头 / 片尾标记 | 条件支持，读取服务端 markers | 条件支持，读取 MediaSegments / 章节标记 | 条件支持，读取章节标记 | 兼容映射保留，待验证 |
| 播放进度上报、停止转码会话 | 已接入 | 已接入 | 已接入 | 已接入，使用原生接口 |

- **原画与转码的音频能力不同。** 原画不受表中转码音频格式和声道限制。表中的声道数指服务器输出；本机默认解码为立体声 PCM，功放直通还受 HDMI 能力、设备和接收端限制。
- **副字幕属于共同的播放器能力。** 只允许选择当前播放源已有的轨道。转码不会为了副字幕再请求一条内封字幕，不能据此推导支持同时保留两条内封字幕。
- **Jellyfin/Emby 的 MKV 输出**从指定起播点生成，跳转需要重建播放流。所选内封字幕可由本机渲染，是否可复制原音频仍由服务端决定。
- **轨道记忆分两层。** 本机文件 / 剧集语言记忆是共同功能；服务端记忆由 Plex 的独立保存请求、Jellyfin/Emby 的播放上报、飞牛的原生播放记录完成。服务端用户设置可能影响是否保存，副字幕选择只对当前视频 / 版本生效。

## 飞牛影视的接口与验证边界

飞牛使用独立的 `server-fnos` 模块，不依赖 `server-jellyfin`；协议上仍同时使用原生接口和飞牛提供的 Jellyfin 兼容接口。

| 内容 | 当前实现 |
|---|---|
| 原生接口 | 搜索、常用筛选排序分页、类型列表、进度与已看状态、准确轨道信息、转码创建与停止 |
| 兼容接口 | 登录与连接检查、媒体库、目录 ID 映射、详情基础数据、季 / 集结构、原画地址、外挂字幕和图片 |
| 本地回退 | 最近观看排序使用兼容数据的 `LastPlayedDate`；完整标清筛选使用视频宽度 |

搜索和原生分页结果仍需与兼容目录关联可播放文件 ID。目录缓存 30 秒，播放上报和标记观看会使缓存失效，大型媒体库首次加载仍可能较慢。最近观看或标清查询还需要收集全部原生结果后在本地处理。

本次飞牛实测限定 **影视服务版本 0.8.43**：

- 已验证电影 / 剧集浏览、搜索、筛选排序、续播、进度与已看同步，以及转码起播、跳转、画质和字幕切换。
- AAC、AC3、EAC3 原样保留有输出音频包与源数据比对证据；5.1 输出已验证。请求 8 声道的样本仍输出 5.1，当前不提供 7.1。
- HDR10 → SDR 已验证请求及输出色彩元数据；不代表所有 HDR / 杜比视界素材的色彩还原均已验收。
- 原生 HLS 可携带所选文本字幕；当前播放计划也可能选择烧录。图形字幕按烧录处理，不提供任意内封轨道的通用保留能力。
- 合集、播放列表、演员作品和相关推荐均尚未接入。演员本地作品的原生接口已探测可用；推荐未找到可用接口，不能据此断言飞牛产品本身不支持。
- 未单独接入原生章节、片头片尾接口，也未完成这些功能及多版本选择的实播验收。

原生请求复用登录会话，并从服务器公开网页资源动态读取签名参数；网页协议变化可能需要更新适配器。

## 共同限制

所有服务器当前均不提供音乐 / 照片浏览、直播电视 / DVR、离线下载，以及合集 / 播放列表的创建和编辑。媒体能否流畅解码、HDR / 杜比视界能否正确输出，不由服务器类型单独决定。

Plex、Jellyfin、Emby 的表格按当前实现与接口测试整理，没有针对所有服务端版本重新完成全功能实测。跨设备、版本及字幕 / 音频组合的结论应保留各自验证范围。
